What do these columns mean?
VAL / VAH: bottom and top of the last 3 days' range, trimmed 15% each side. Price inside = no trade.
Monthly AVWAP: average price this month, weighted by volume. Above it favours CE, below favours PE.
Side: CE if the close is above VAH and AVWAP, PE if below VAL and AVWAP, "inside" otherwise.
Trend: "aligned" when the 20- and 50-day averages point the same way. Only aligned stocks make the watchlist.
Quality: 0–100 grade from trend, volume, close strength, coil and AVWAP distance. ≥ 60, top 10 per side, become today's watchlist (amber edge). It is not a win chance.
Trigger / SL / T1–T3: spot levels. Entry only when a 5-minute candle closes beyond the trigger; targets are 1R / 2R / 3R from the trigger (they shift with the real entry).
Strike: planned option for watchlist stocks (delta ≈ 0.45, real contract, nearest expiry with ≥ 3 days left).
Lot: from the broker's contract list.
